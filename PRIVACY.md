# WinZones Privacy Policy

_Last updated: November 20, 2026_

WinZones is a window manager for Windows, made by Coursion Studio. This policy explains what data WinZones handles.

## The short version

**WinZones does not collect, store remotely, sell or share any personal data.** It has no accounts, no analytics, no telemetry, no ads and no tracking.

## What stays on your PC

To do its job, WinZones reads the titles, process names and positions of the windows you have open, and moves those windows when you ask it to. This happens only in memory on your device. It is never written to a server or sent anywhere.

Your settings (layouts, shortcuts, app rules and preferences) are saved in a file on your PC, in `%APPDATA%\WinZones\winzones.json`, or next to the app in portable mode. You can delete that file at any time.

## Network access

- **Microsoft Store version:** WinZones makes no network connections. The Microsoft Store handles updates.
- **GitHub version:** to offer updates, WinZones asks GitHub (`api.github.com` and `github.com`) for the latest release a few seconds after start and then every 6 hours. You can turn this off in **Settings → General → Updates**. These requests send only standard technical information that any web request includes (such as your IP address, and an app name and version in the request header). They don't send anything about you or your windows. GitHub's handling of that data is covered by the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

## Children

WinZones is a general-purpose utility, it collects no data from anyone, and that includes children.

## Changes

If this policy changes, the new version will be published here with a new date.
